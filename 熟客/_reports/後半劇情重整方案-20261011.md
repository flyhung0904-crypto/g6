# 〈熟客〉後半劇情重整方案：信翔講完收班規則之後（2026-10-11）

> 範圍：第四章「只有店長不管這些。」之後到第五章結束。Lighter 判斷「後續太過重複拖沓」。

## 一、目前這一段在重複什麼

信翔講完規則後，讀者手上已有兩件事：右上角的杯子是彥勳收班的習慣，三點半彥勳還在樓上。後面卻把同一批資訊又演了好幾遍。

| 重複的東西 | 出現位置 |
|---|---|
| 收班流程（關音響、收杯、拖地、右上角） | 第四章信翔口述 → 第四章立航留下來看彥勳收一遍 → 第五章宇辰再看彥勳收一遍 |
| 交接本時間先寫好 | 第二章立航翻交接本 → 第四章立航看彥勳先寫時間 → 第五章尾聲宇辰把交接本壓在名單上 |
| 下樓抽菸、五分鐘後鐵門、兩分鐘後彥勳下來借火 | 第一章回想 → 第二章 → 第四章又一次 |
| 案情整理 | 第四章路口「立航把他知道的講出來：房東說的、信翔說的、杯架……」 → 第五章宇辰面對彥勳時讀者再拼一次 |
| 彥勳「我弄好就下去」 | 第一、二、四章各一次 |

第四章從收班到路口約 1,000 字、第五章開場看收班約 150 字在做同一件事（字數以工具實數計，不含空白）：讓角色再確認一次讀者已經知道的事。

## 二、兩個方案

### 方案 A：一夜收束（建議）

**第四章**（信翔講完規則之後）
1. 立航想起魏哥的杯子扣在右上角，那天收班的是彥勳。保留，兩三句。
2. 立航想起上個月魏哥問他信翔做得怎樣，他說的那句話。保留。
3. 晚上店長講嘉義做法事，彥勳說「他去的話，就回不來了」。保留，這是第五章嘉義那場的伏筆。
4. ⛔ 刪：立航留下來幫彥勳收班、看完整套流程、看彥勳先寫交接本時間、第三次下樓抽菸借火。
5. 改：收班後立航和宇辰在騎樓下，彥勳照常說「我弄好就下去」。立航不等，直接問宇辰：「上禮拜三，他有下來嗎？」宇辰回想，想不起彥勳的臉。「我想不起來他的臉。」「因為他不在。」路口那段的案情整理整段刪。
6. 交接本先寫時間這條線索，改由立航一句話帶過：他翻到上禮拜三那頁，三點十分寫在「魏哥留」前面，字跡和平常一樣工整，那時彥勳還沒說「你們先走」。這條線索只出現在這裡，第二章那次已經鋪過。
7. 章末：「明天他收班。你去問他。」

**第五章**
1. ⛔ 刪：宇辰看彥勳收班那一大段。開場直接進洗杯台，兩個人一個洗一個擦。
2. 其餘照舊：彥勳的自白、信翔清置物櫃、安全帽、嘉義做法事、月底那晚。
3. 尾聲宇辰交出交接本那一場，是這條線索第三次出現。可以改成宇辰只說「我說他有下去，是我講錯」，不再翻交接本。

**效果**：刪約 1,000～1,200 字，全篇約 20,800 字。三種重複（收班流程、交接本、下樓借火）各只剩必要的一次。

### 方案 B：讓宇辰自己發現

**第四章**停在信翔講完規則，加上立航想起魏哥問過他那句話。立航什麼都不跟宇辰講，把他知道的事放在心裡。

**第五章**由宇辰的視角，在洗杯台邊自己發現：他幫彥勳擦杯子，看見彥勳寫交接本，時間寫在「你們先走」之前。宇辰想起自己對立航作的證詞，當場問「那天你沒有下去」。

**效果**：刪掉第四章收班到路口那段（約 1,000 字）。立航「看得出來卻不講」這條代決線收得更乾淨，宇辰從替人作證的人，變成自己發現真相的人。代價是信翔「三點半」那條證詞要另外交到宇辰手上，否則宇辰只有交接本一條線索，問得太快。

## 三、要先跟親修對齊的四件事

1. 第二章親修寫杯子和外套「交給了後來來調查的人」：碰到 R10，也跟第五章魏哥爸爸還外套對不上。要嘛改回交給嘉義的家人，要嘛刪掉第五章還外套那段。
2. 第三章立航那句親修改了說法，第四章他對魏哥說的那句還是舊句，兩句已經不一樣。要讓「他對宇辰說的跟對魏哥說的一字不差」這個回聲成立，兩句得統一。
3. 第四章親修把房東那晚改成店長收班（禮拜六），接「隔了兩天」就是禮拜一，但下一句寫信翔開店（原本是禮拜二）。
4. 親修刪了第二章店長說「外套蓋著」和招牌的光，第五章尾聲店長說「樓下招牌的光照進來，我看到他蓋著外套」要跟著改。
