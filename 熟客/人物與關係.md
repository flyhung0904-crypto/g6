## 二、關係

```
     魏家（嘉義・不出場）
          │ 缺一個信得過的倉管
          ↓
       魏仲凱 29（熟客・股東）
          │ 代簽：離職登記・轉客名單・退租
          │ 調得動店長（出過錢、消費最大、房子是他介紹的）
          ↓
       黃信翔 22 ←──── 許家豪 25（分租室友・主承租人）
          │                     那晚殺了魏
          │ 熟客被轉走
          ↓
   曾宇辰 23　　鄭立航 29
   （各接一半黃的熟客）
          ↑
          │ 鄭習慣替曾把話講完
```

| 關係 | 內容 |
|---|---|
| 曾 ↔ 鄭 | 雙男主。鄭習慣替曾把話講完；收在鄭停下來 |
| 鄭 → 魏之死 | 他是發現的人，他的「老樣子」成了全店的說法 |
| 魏 → 黃 | 同鄉，介紹他進店、介紹他房子。替他安排回嘉義，進魏家的物流行。⛔ R7：兩人之間禁曖昧化 |
| 魏 → 店長 | 股東、出過周轉金、最大的消費。店長替他排班表、擬轉客名單 |
| 許 → 黃 | 室友、同事。替他回答、替他擋客人的問題。⛔ 不寫成戀愛 |
| 許 → 魏 | 一週前就從房東那裡知道黃的房間被退了；那晚兩人在吧台尾端推擠 |
| 轉客 → 曾、鄭 | 黃的熟客轉到兩人名下，他們成了得利的人 |
