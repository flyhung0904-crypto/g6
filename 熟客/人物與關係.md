## 二、關係

```
     魏家（嘉義・不出場）
          │ 缺一個信得過的倉管
          ↓
       魏哥 29（熟客・股東）
          │ 代簽：離職登記・轉客交代・退租・嘉義到職表
          │ 調得動店長（出過周轉金、消費最大、替店長簽收貨單）
          ↓
       信翔 22 ←──── 彥勳 25（教他入行・分租室友・主承租人）
          │                     那晚推倒了魏
          │ 熟客被轉走
          ↓
   宇辰 23　　立航 29
   （各接一半信翔的熟客）
          ↑
          │ 立航習慣替宇辰把話講完
```

| 關係 | 內容 |
|---|---|
| 宇辰 ↔ 立航 | 雙男主。立航教宇辰怎麼回客人，也習慣替宇辰把話講完；第 5 章他第一次停下 |
| 立航 → 魏之死 | 他是發現的人，他的「老樣子」成了全店的說法 |
| 店長 → 魏之死 | 四點半回店看見魏躺著，以為老樣子就走了；之後一句「家屬那邊我處理好了」把事情收掉 |
| 魏 → 信翔 | 同鄉，介紹他進店、介紹他房子。替他安排回嘉義。⛔ R7：兩人之間禁曖昧化 |
| 魏 → 店長 | 股東、出過周轉金、最大的消費、順手替店長簽收貨單。店長照他的交代排班表、轉客 |
| 彥勳 → 信翔 | ⭐ 教他入行的前輩（綠茶線：教他對客人說自己是誰、怎麼笑、哪些話不講）；室友；替他回答、替他擋客人的問題。⭐ 感情只在底下、單方面、⛔ 不說破（R7 v5.1） |
| 彥勳 → 魏 | 一週前就從房東那裡知道信翔的房間被退了；那晚魏說房租他也安排好了，又說信翔在這裡學的那套回去用不到；兩人在吧台尾端推擠 |
| 轉客 → 宇辰、立航 | 信翔的熟客轉到兩人名下，他們是收下的人 |
